Contribute papers from Zotero or EndNote

How this works. Export your reference(s) from Zotero (right-click → Export Items → format RIS) or EndNote (File → Export → output style RefMan (RIS) Export). Drop the .ris file below. Fill in your annotation for each paper, then click Open pull request on GitHub. GitHub will open a pre-filled page — sign in if needed, scroll down, and click Propose changes. The rest (index entry, GitHub issue for comments and upvotes) is handled automatically when the PR merges.
