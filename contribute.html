Add a paper and your commentary — by file, link, or PDF

How this works. Add a paper any of three ways below, write your commentary, then click Open pull request on GitHub. GitHub opens a pre-filled page — sign in if needed, scroll down, and click Propose changes. The rest (index entry, GitHub issue for comments and upvotes) is handled automatically when the PR merges. You can add several papers before submitting; each gets its own card.

1 · From a reference file

RIS (Zotero: Export Items → RIS; EndNote: RefMan (RIS) Export) or BibTeX (.bib).

Drop a .ris or .bib file here

or

Multiple files are fine. Bulk imports (no per-paper annotation) can instead be committed to imports/.

2 · From a link or DOI

Paste a DOI or article URL — we'll pull the metadata from Crossref.

3 · From a PDF

We'll read the title/author from the file's metadata. Signed in, the PDF is uploaded with your submission; otherwise add it to papers/pdfs/ yourself when you open the PR.

Only needed when you're not signed in — signing in credits the annotation to your GitHub account automatically.
